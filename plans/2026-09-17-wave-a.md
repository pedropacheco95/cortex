## Ground rules for every task

  file; the task is done when the named `pnpm vitest run …` command is green.

  import). Nothing here imports an SDK or touches the network. Batch 2 spawns **no** subprocess:
  staleness is a sha256 of a file body, never `git`.
- **RULES.md rule 6.** The stale marker never changes a decision: it rides on the `allow` summary and
  on the Rule 7 `deny` reason's first line, and a hashing failure means no marker, no log entry.

  summary (200/300 chars), the combined marker ceiling (+200) and the deny reason (1,000 chars);
  purpose trimming makes room, the marker is never cut.

  this wave: `ProjectIndex` (+`idToFiles`); `resolveId` (duplicates → `undefined`); `checkXrefUnique`
