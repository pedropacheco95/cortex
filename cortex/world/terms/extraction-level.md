One of the four depths at which insight extraction runs — L1 structural (deterministic tree-sitter/graph/centrality), L2 purpose (per-file LLM purpose line), L3 deep per-file understanding (main players, insights, file map for important files), and L4 cross-file semantic graph (concepts, semantic edges, patterns). The target level is configurable per project.
